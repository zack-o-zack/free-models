## Provider and pipeline repairs

OpenCode's documentation outlived retired models and now includes a native System One model without
an AI SDK package. Discovery intersects documented free offers with the live model list, preserves
System One's protocol, and derives API base URLs from the published endpoints.

[BazaarLink's free tier](https://bazaarlink.ai/free) now uses weighted daily units, separate account
rates, a site-wide rate cap, and an account concurrency cap. These units are retained as published;
weighted units are not converted into requests or tokens.

[TokenRouter pricing](https://api.tokenrouter.com/api/pricing) no longer contains eligible native
`-free` offers. A valid empty selection retires the old offer instead of stopping all discovery.
Malformed data and failed authenticated requests still fail discovery.

The lint tool was upgraded to 0.18.1, removing the unpatched `braces` dependency and updating the
other affected transitive dependencies. `bun audit` reports no known vulnerabilities.

## Verification limits

Discovery verifies listings and published free-tier terms; it does not exercise inference or
prove account-specific access. Metadata enrichment uses OpenRouter and may not cover models
exclusive to other providers. The refresh reports missing metadata and retains existing records;
it does not manufacture capabilities or context limits.
